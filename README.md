# 🌍 Projeto: Ecologia e Sustentabilidade

Este é um site educativo desenvolvido como parte integrante da avaliação da disciplina de **Desenvolvimento Web**. O projeto utiliza tecnologias web fundamentais para disseminar conhecimentos críticos sobre a preservação do meio ambiente e o papel da sustentabilidade na sociedade moderna.

## 🎯 Objetivo
O portal foi criado com o intuito de facilitar o acesso à informação sobre crises ambientais contemporâneas, unindo conceitos teóricos de ecologia a soluções práticas que podem ser adotadas por indivíduos e governos.

## 📚 Conteúdos Abordados
* **Fundamentos de Ecologia:** O equilíbrio dos ecossistemas.
* **Sustentabilidade:** O tripé social, econômico e ambiental (ESG).
* **Desmatamento:** Impactos nos ciclos hídricos e na biodiversidade.
* **Poluição Oceânica:** O desafio dos microplásticos e a economia circular.
* **Guia de Ação:** Como contribuir para um futuro mais verde.

## 💻 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica de todo o conteúdo.
* **GitHub Pages:** Utilizado para a hospedagem e publicação online do projeto.
